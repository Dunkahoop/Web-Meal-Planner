# Web Meal Planner

This was meant to be a web application that allowed the user to add recipes they would usually make, and when the user would input a list of ingredients purchased from the grocery store, the app would automatically determine a meal plan. I also looked to use an API call that would show the user what products were on sale, so they could take them into consideration when putting together their grocery list. I even wanted to save the last grocery list so all the leftover food was used.

The idea for this app came from a coworker of mine, Sam, who thought it would be useful for his wife. Unfortunaetly, as I kept working on the app (on-and-off given I was also in my final college term), the complexity of the app, as well as my relative lack of experience with developing pure javascript apps, the project started to spiral out of control. Adding the necessary features became too complex, bugs that I could not fix kept appearing, and despite my best efforts, I could try to understand what the code I wrote was doing, but it kept having problems that I couldn't fix, therefore it's quite a mess. Although I didn't want to, I decided this project has gone off the rails and it would be best to cut my losses and cease work on it. It's very dissapointing, but thankfully Sam isn't too worked up about getting this app, he said it was a fun suggestion for me to try. I never sent him the link to this repo, but if you're reading this, Sam, i'm terribly sorry this app didn't turn out, and I don't recommend using it right now given how buggy it is.

I may decide to completely redo this project later down the road, but for now I need to let it go. I'll leave the code open in case anyone has any ideas to fix what I did, or at least borrow parts of it. Do what you want with the code, I don't care.
