This is that web app you and your wife were interested in me developing. Right now it's a work-in-progress. Soon enough I'll get the styling done, right now I'm working on functionality. I have some ideas for getting discount info, but right now I'm still looking at it

To install and use this app, you need to do the following:

- Click on the green button reading `< > Code`
- Select the dropdown option `Download ZIP` at the very bottom
- Unzip the package in a file of your choice (preferably somewhere easily accessible)
- Open the file `webmealplanner.html`
- Enjoy!
